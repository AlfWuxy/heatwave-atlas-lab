# 粒子热场：模型、参数与验证

版本：2026-09-27。页面 `#particles`。这是独立编写的二维理想化机制实验，没有调用天气预报模式，也没有把本站的六点历史资料作为此模型初值。

## 研究问题与科学范围

在静止、初始均温的封闭流体域内，加入局部有限温度扰动，观察温度如何驱动浮力，流场如何输送温度，以及扩散如何平滑差异。提供暖团上升、冷团下沉、冷热相遇三种初态；关掉浮力并从静止重置得到纯扩散对照。

粒子是示踪点，不是空气分子或“热量小球”。粒子的位置由速度场推进，颜色取当前位置的温度异常。增加显示粒子数不改变温度或速度的计算网格。

这里的时间、空间、温度和速度均为无量纲量，尚未按实际城市或天气事件标定。不应把 `t=6` 称为六秒或六小时，也不应把温度异常 `+1` 写成 `+1°C`。

## 方程与边界

竖直坐标 y 向上，二维 Boussinesq 形式为：

```
∇·u = 0
∂u/∂t + (u·∇)u = −∇p + ν∇²u + b θ e_y
∂θ/∂t + ∇·(uθ) = κ∇²θ + Q
dx_particle/dt = u(x_particle,t)
```

θ 是相对初始参考态的温度异常。均匀 θ 的常量浮力可由静水压梯度平衡，并不自行产生持续上升。关闭浮力仅去掉 `bθ` 项，不会瞬间消除已有动量。纯扩散按钮同时重置初态与速度。

域为 `[0,1.6]×[0,1]`；四壁不可穿透、无滑移，温度无通量。顶部是模型边界，不能解释成真实热穹顶。

| 参数 | 页面当前值 |
|---|---:|
| 计算网格 | 96 × 60 |
| 固定外部时间步 | 1/60 |
| 黏性系数 ν | 0.0002 |
| 热扩散系数 κ | 0.00015 |
| 浮力系数 b | 0.28 |
| 单暖团中心 / 峰值 | (0.46, 0.17) / +1 |
| 单冷团中心 / 峰值 | (0.54, 0.83) / −1 |
| 相遇初态中心 / 峰值 | (0.39, 0.17) / +1；(0.61, 0.83) / −1 |
| 初态高斯团半径 | 0.085，以域高度计 |
| 手工温度扰动半径 | 0.06，以域高度计 |

表中中心坐标归一化到 `[0,1]²`，x 物理坐标须乘以1.6。每次点击加入高斯分布有限温差，峰值为 `±0.65×强度`；拖动时每次接收的峰值为 `±0.12×强度`。输入有主线程节流与背压，慢设备的长笔触不保证与快设备积分输入相等；因此精确复现应使用预设，手工笔触属于交互探索。输入积分按实际进入网格的数值记账。

## 数值实现

- MAC 交错速度网格；半拉格朗日速度平流、显式黏性及压力投影。压力 Poisson 方程采用预条件共轭梯度求解，RMS 残差目标约为 10⁻⁶；页面报告实际速度散度。
- 温度采用保守有限体积通量、MC 斜率限制器与 SSP-RK2。模型按对流与扩散稳定条件进行内部子步。
- 速度壁面法向分量为零，切向镜像用于实现无滑移；温度边界没有向外通量。
- 没有装饰性的涡度增强、随机流动力、额外“热浪旋涡”或任意温度衰减。
- 模型在 Web Worker 计算；主线程只负责交互、固定步派发和显示。每次最多推进4步，设备繁忙时减慢模拟时间，避免无限积压。离开画布或隐藏页面后停止派发，不补算离开时间；在途批次可完成。

有符号温差积分 `∫θdA` 应等于初始积分加累计热冷输入。页面“热异常积分误差”是二者绝对差，并非相对百分比，也不是以焦耳计量的能量。冷热会相互抵消，误差很小不足以单独证明局地解准确；必须结合其他测试。`maxSpeed`、暖冷团重心等在求解器诊断接口中可取。

## 显示与交互

WebGL2 使用 transform feedback 搬运粒子、实例化绘制短轨迹和 RGBA8 拖尾。低／中／高分别为16,384／65,536／262,144粒子；兼容 Canvas2D 路径为2,048／4,096／8,192。若 GPU 初始化失败，会创建新画布再切换兼容路径；用户也可手动选择。

两条路径使用同一速度和温度场、中心格点双线性插值与中点搬运。x 方向位移除以域宽1.6。粒子有显示寿命并在域内重新均匀播种；重生不能解释为真实物质消失或产生，重生位置之间不绘制轨迹。

红暖蓝冷，固定端点为 −1 与 +1，零异常近暗灰。实际颜色响应采用固定的 `min(|θ|,1)^0.6`，以看清较弱异常；不随每帧最大值自动拉伸。超过端点会饱和，实际极值仍由诊断读数给出。淡温度底图、轨迹累积和亮度合成属于可视化：拖尾记录近期路径，其颜色来自绘制该段时的温度，不能作为严格的当前等温线或数值量尺。光标数值按当前场采样；画布下方给出固定色标。

暂停时位置和寿命冻结；在暂停中加入温度后，清除旧拖尾并按原位置重新着色。重置清空速度、时间和旧轨迹。切换显示密度只重播种粒子，不重置模型。兼容显示的性能和密度较低，但物理计算相同。

鼠标、触屏可以点击／拖动；键盘聚焦画布后方向键移动光标、Enter 施加扰动、空格播放／暂停。系统减少动态效果开启时默认暂停。支持单步与按钮形式的热冷输入。

URL 保存初态、浮力、强度、显示密度、底图、粒子随机种子与后端偏好。它不保存手工笔触、计算进度或完整流场，不是运行快照。

## 已执行的物理验证

运行 `npm test`，包含既有8项物理测试和新增9项求解器测试。新增测试涵盖：

1. 均匀温差、零速度的静水压平衡。
2. 关闭浮力后只扩散，无凭空产生的速度、温度峰值不超调。
3. 暖团上升、冷团下沉及对称初态的镜像重心。
4. 冷热相遇及靠近壁面的输入积分记账。
5. 压力投影、不可穿透边界与有限数值。
6. 时间步1/30、1/60、1/120的暖团重心比较。
7. 网格24×15、48×30、96×60的暖团重心比较。
8. 重置与确定性复现。
9. 面积平均、域积分与非法输入。

开发机 Node 测得：默认相遇初态至 t=6，暖团重心约0.692、冷团约0.308；温差积分误差约5×10⁻¹⁰，RMS散度约10⁻⁶。时间步加密的 t=2 暖团重心相邻差约8.79×10⁻⁴→4.40×10⁻⁴；网格加密差约8.72×10⁻³→2.03×10⁻³。支持所测重心的收敛趋势，不能声称完整湍流解已经网格无关，更不代表观测验证。设备性能数字仅属本地测试，不承诺所有设备帧率。

## 与真实热浪的区别

热对流只展示热输送的一部分。这个不可压缩模型没有气团绝热压缩、辐射收支、湿过程、陆面干旱反馈、地形或大尺度天气环流。既有热量实验室中的干绝热压缩与地表能量模型继续作为独立实验。

网站现已另行实现重庆—四川、巴黎周边和波特兰周边的区域风温回放，使用逐小时0.25° ERA5格点，10米风驱动示踪点、2米气温着色。该地图没有使用本热箱方程，仍不是完整热量收支或历史气块轨迹。资料、层次和插值边界见《区域风温回放方法》。
